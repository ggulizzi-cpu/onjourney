# HIS EXCELLENCY

An ultra-realistic mockumentary sitcom about George Washington and the Continental
Army — The Office's grammar, South Park's nerve, early-Simpsons craft. Five-minute
episodes, produced end-to-end with the Higgsfield MCP (Seedance 2.0, 1080p).

- `bible/series-bible.md` — premise, cast, tone rules, running gags, production spec
- `episodes/e001-first-day-of-command/` — the pilot
  - `script.md` — full shooting script with historical notes
  - `shots.md` — per-shot Seedance prompts (generated after script approval)
  - `production.md` — job IDs, credits, retries (generated during the shoot)
